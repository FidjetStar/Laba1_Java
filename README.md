#### Текст задачи

Необходимо реализовать метод таким образом, чтобы он возвращал true, если
число x делится нацело на 3 или 5. При этом, если оно делится и на 3, и на 5, то

#### Текст задачи

дня недели. Необходимо реализовать метод таким образом, чтобы он выводил
на экран название переданного в него дня и всех последующих до конца недели

#### Алгоритм решения

1) Взять строку x и передать её в switch.
2) Для каждого дня недели (от понедельника до воскресенья) создать case.
3) В каждом case (кроме воскресенья) НЕ ставить break — чтобы выполнялись все последующие дни.
4) После воскресенья поставить break — чтобы остановить выполнение.
5) В default вывести "это не день недели" и поставить break.
6) Все названия дней писать с маленькой буквы — как в примерах задачи.

Необходимо реализовать метод таким образом, чтобы он возвращал новый

#### Алгоритм решения

4) Скопировать оставшиеся элементы arr (от pos до конца) со сдвигом на ins.length.
5) Вернуть новый массив p.
